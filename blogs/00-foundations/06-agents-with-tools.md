# Marketing Agents with Tools: Scope, Desks and Least Privilege

**Topic suggestion:** Marketing Agents with Tools: Scope, Desks and Least Privilege

**Summary:** What an agent is in practice: a model plus tools plus a scoped context. Explain why giving an agent every tool makes it worse, how to scope by task (a 'desk'), why read access is broad but write access is narrow, and why tool names in prompts go stale. Aimed at marketers building their own Claude-based workflows with MCP.

**Approach:** LLM

**Grounded in Meelu:** Desk scopes, the in-app MCP proxy that lists only allowed tools, and add_desk to widen scope mid-task.
