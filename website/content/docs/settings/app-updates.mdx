---
title: App updates
description: How Meelu tells you about a new version, and how to install it.
---

Meelu is in beta and changes often. New versions fix bugs and add features, so it is worth updating when one comes out.

## How you find out

While Meelu is open, it checks for a new version every 10 minutes. When one is out, a banner appears at the top of the screen: **Meelu (version) is available**, with the version you have now.

You can also check yourself. Open **Settings** and find the **App updates** card. Click **Check for updates**. The card then says either that you have the latest version, or that a new one is available.

## Install an update

<Steps>
<Step>

### Download it

Click **Download** in the banner, or **Download** (version) on the **App updates** card. The new installer downloads in your browser.

</Step>
<Step>

### Quit Meelu

Quit the app completely. Any running crawl or task stops.

</Step>
<Step>

### Install it over the old one

Open the installer and install it the same way as the first time. On a Mac, drag Meelu into **Applications** and replace the old copy. Your sign-in and settings stay.

</Step>
</Steps>

You may see the same security warning as on your first install. See [Install the app](/docs/getting-started/install#open-it-for-the-first-time) for how to get past it.

<Callout type="info" title="Installed from the Microsoft Store?">
Then the Store keeps Meelu up to date for you. The **App updates** card says so, and there is nothing to download.
</Callout>

## Dismissing the banner

Click the **X** on the banner to hide it. It stays hidden for that version. When the next version comes out, the banner appears again.

## What each button does

| Button | Where | What it does |
| --- | --- | --- |
| **Download** | Update banner | Opens the download of the new version in your browser. |
| **X** (Dismiss) | Update banner | Hides the banner until the next version. |
| **Check for updates** | App updates card | Checks for a new version now. |
| **Download** (version) | App updates card | Appears when a new version is out. Opens its download. |
