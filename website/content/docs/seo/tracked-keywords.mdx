title: Tracked keywords
description: Follow where you rank and how search demand moves for the keywords that matter to you.
---

Search Console tells you about searches where you already appear. **Tracked keywords** follows specific keywords you choose, whether you rank for them yet or not. For each one it records your position in Google and how many people search it each month.

Open it from the **Tracked keywords** card on the SEO home screen.

## Start tracking

There are two ways to add keywords:

- **From a cluster.** Open a [keyword cluster](/docs/seo/keyword-clusters) and click **Track its ranking**. This tracks the cluster's main keyword in every one of your markets.
- **By asking Meelu.** Click the **Track my main keywords** task card. Meelu tracks rankings and search volume for the main keyword of every cluster with a winnability of 50 or more. It tells you how many keywords that is before it starts.

Tracking uses credits, so Meelu always tells you the count first. Up to 50 keywords can be tracked in one go. See [Credits](/docs/concepts/credits).

The first time you track a keyword, Meelu also fills in its past positions for about the last twelve months, so you get a history straight away.

<Callout type="info" title="When positions update">
Each tracking run records Google's top 30 results on desktop at that moment. A run happens when you or Meelu start one. Run it again when you want fresh positions.
</Callout>

### Summary cards

| Card | Meaning |
| --- | --- |
| **Tracked** | How many keywords you track in the chosen market. |
| **In the top 10** | How many ranked on page one on the last run. |
| **Moved** | How many changed position since the run before. |
| **Not ranking yet** | How many are outside the top 30. |

### The Keywords table

| Column | Meaning |
| --- | --- |
| **Keyword** | The tracked search. Under it: your page that ranks for it. |
| **You rank** | Your position on the last run, or **not in top 30**. |
| **Change** | Positions gained (▲, green) or lost (▼, red) since the run before. |
| **12-month position** | One bar per month. A taller bar means a better position. Green is the top 10, blue is 11 to 30, and a short grey bar is a month outside the top 30. Hover a bar to see the month and position. |
| **Searches / mo** | Estimated monthly searches. |
| **Demand** | How search interest is moving (see below). |

### Demand labels

Meelu labels demand once it has at least six months of search volume:

| Label | Meaning |
| --- | --- |
| **seasonal** | The busiest month has at least twice the searches of the quietest. Plan the page well before the peak. |
| **rising** | The last three months are up by a fifth or more on the three before. |
| **falling** | The last three months are down by a fifth or more. |
| **steady** | None of the above. |

## What each button does

| Button | What it does |
| --- | --- |
| **Market** menu | Shows the keywords for another country you track. |
| **Find a keyword** | Filters the table by text. |
| **All** / **Going up** / **Going down** | Show every keyword, only gainers, or only losers. |
| **Ask Meelu** (sparkle icon) | Opens a task about your tracked keywords. Desktop app only. |
| Task cards under **Start a task** | Ready-made tasks, listed below. Desktop app only. |

| Task card | What Meelu does |
| --- | --- |
| **Track my main keywords** | Starts tracking the main keyword of every cluster with winnability 50 or more. |
| **Which pages are going up or down?** | Reads the ranking history and names the pages that moved most. For big drops, it names the result that moved above you. |
| **Is demand seasonal?** | Says which keywords are seasonal, when each peaks, and how far ahead a page should be ready. |
| **Who overtook me?** | For each keyword you lost since the last run, names the result that moved above you and what changed. |

## Tips

- Track the main keywords of the clusters you are actually working on, not every keyword you can think of.
- A drop of one or two places is normal. Look for steady moves over several months.
- Seasonal keywords need the page live and ranking before the peak, so check **Is demand seasonal?** early.
