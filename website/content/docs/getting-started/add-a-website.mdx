title: Add your first website

---

A **website** in Meelu is one domain and everything Meelu learns about it: its pages, its Google data, your content drafts, your notes and your saved prompts. You add it once and then pick it from the website switcher whenever you work on it.

## Add it

<Steps>
<Step>

### Click Add a website

The button is at the top of the sidebar, just under the Meelu logo. If you already have a website, click the website switcher there and choose **Add a website** at the bottom of the list.

</Step>
<Step>

### Type the website address

In **Website**, type the address your site actually serves on, including `www` if it uses it. For example, `www.example.com`. You do not need `https://`.

</Step>
<Step>

### Type the business name

In **Business name**, type the name you want to see in the switcher, for example "Example Co".

</Step>
<Step>

### Click Add

Meelu saves the website, switches to it and opens the Site desk.

</Step>
</Steps>

<Callout type="info" title="Why the exact address matters">
Meelu crawls the address you type. If your site lives at `www.example.com` but you type `example.com`, the first request may redirect, and the numbers Meelu matches from Google can differ. Open your site in a browser and copy the address from the address bar.
</Callout>

## What it costs

A website costs 0.5 credits a day. The fee is taken when you add it and every 24 hours after that. One credit is one US dollar.

Your first website is free for the first day of your account. If your balance runs out, the website pauses and picks up again once you add credits. See [Credits and billing](/docs/concepts/credits).

## What happens next

Right after you add the website, Meelu reads your homepage and writes a short description of what the site is about. This runs in the background. You can see it on the Site desk, in the card called **The website**.

The card shows one of three labels:

| Label | What it means |
| --- | --- |
| **Writing it up…** | Meelu is reading the homepage now. |
| **Described** | The description is ready. It shows under the label. |
| **Not described yet** | Nothing has been written yet. Click **Write it now** to start it. If it failed, click **Try again**. |

The same card holds the settings the crawl runs under, such as your target countries, language and sitemap address. You can change them there. The Site desk docs cover each field in [Website profile](/docs/site/website-profile).

## More than one business

A second business is a second website, not a second account. Add it the same way. Each website keeps its own pages, content, posts, notes and saved prompts. Your profile (the "who Meelu writes as" details) is shared across all of them.

To switch, removing a website, and what happens when a website is paused, see [Websites](/docs/settings/websites).

## What each button does

| Button | What it does |
| --- | --- |
| **Add a website** | Opens the form to add a new website. |
| **Add** | Saves the website, charges the first day (unless it is your free first website), and opens the Site desk. |
| **Cancel** | Closes the form without adding anything. |
| **Write it now** | Asks Meelu to read the homepage and write the description now. |
| **Try again** | Retries the description after it failed. |
